# v0.4.6-banana.10

## 发布概览

- 发布日期：`2026-09-09`
- 发布版本：`v0.4.6-banana.10`

## 本次更新

- 新增 `gpt-image-2.5-sunburst`。
- 新增 `gpt-image-2.5-flare`。
- 新增 `seedream-5-pro`。
- 三个模型均可在 Gallery 和 Agent 图片模型选择器中使用。
- 三个模型均复用现有 OpenAI Images 生成、参考图和遮罩编辑接口。
- GPT Image 2.5 Sunburst 与 Flare 支持 1K、2K、4K。
- Seedream 5 Pro 仅支持 1K、2K；已有显式 4K 尺寸会自动按原比例降到合法 2K 尺寸。

## 兼容性

- 现有配置、历史任务和自定义 OpenAI 兼容模型保持原有行为。
- `auto` 尺寸、质量、格式、审核、压缩率和生成数量参数保持不变。
