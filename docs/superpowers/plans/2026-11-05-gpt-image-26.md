## Acceptance examples

GIF request: `{ output_format: 'gif', complexity: 'high', frame_count: 9, frame_duration_ms: 200 }`.

SVG request: `{ output_format: 'svg', svg: { model: 'gpt-6.1-sol' } }`; no stream or partial_images fields.

Only the GPT Image 2.6 `-1k` lines expose output format and complexity controls, and their size choices are limited to 1K. Base 2.6 lines retain the special-offer label and do not expose those controls. GIF/SVG original bytes and formats are preserved on download and backup.
