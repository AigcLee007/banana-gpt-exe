# 视频模型说明入口

在视频工作台模型选择行右侧增加圆形信息按钮。鼠标悬浮或键盘聚焦时显示 MiniMax H3 与 Wan 3.0 的对比表，点击可以保持展开，再次点击、点击外部或按 Escape 关闭。指针移动到面板后可以继续阅读和滚动；手机支持点击。

面板使用现有主题、模型 Logo 和价格配置，通过 portal 渲染避免创建面板裁剪，自动避让视口边缘，窄屏保持两列对照并支持内部滚动。内容包括两档 H3 / 单档 Wan 输出分辨率、输出时长、基础生成积分价格、参考素材收费、图片/视频/音频数量上限及首尾帧支持。所有价格仅显示积分，不显示人民币金额或金额换算备注。标注 Wan 参考视频将输出上限缩短为 15 秒，音频需要搭配图片或视频，参考视频和音频各合计不超过 15 秒。

价格和能力从现有 VIDEO_MODELS 派生。内部换算规则仍为 1 元 = 12.5 积分；H3 图片前 5 张免费，之后 0.625 积分/张，视频根据输出档位按输入秒数收费，音频免费；Wan 当前按输出秒数收费，参考素材不另收费。文案面向用户，不含供应方、插件或内部 API 信息，不作未经验证的画质、速度优劣判断。

保留当前项目已有修改。验证对照表与收费规则的静态测试、入口集成测试，以及真实浏览器中的跨面板悬浮、点击、键盘关闭、外部点击、窄屏和深色布局。不发送生成请求。
